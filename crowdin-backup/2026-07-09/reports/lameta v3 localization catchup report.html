Safety rails that were enforced

  • Backup-first, committed to git — TM, glossary, builds, every file, every language, every string ID, before the first mutation. Verified against the audit numbers before proceeding.
  • Root untouched — zero writes or deletions on the v2 files; the deletion script asserts branch id 66 on every candidate.
  • Rehearsal branch — every mutating mechanic proven on a scratch branch first.
  • Non-destructive defaults — source updates keep translations; translation uploads add unapproved suggestions to empty strings only; TM pass perfect-match only.
  • Everything scripted and auditable — the recovery reports record the source of every migrated translation; all scripts are committed and rerunnable.

Decisions honored

v2 stays live (root read-only; V3 remains a branch) · TM-only pre-translate (no machine translation anywhere) · folder naming fixed (pt-BR/zh-CN, remap deleted).
