## Improvements

- Alpha, beta and regular versions side by side
  - Alpha, beta and regular versions of lameta can now be installed on the same computer. This version installs as "lameta alpha", with its own settings and its own list of recent projects, so it doesn't replace the version you already use.
  - On Windows, double-clicking a project's .sprj file now opens it in the version of lameta that you installed or opened most recently.
  - If you use an alpha or a beta, the update notice now also tells you about newer betas and regular versions.

## Fixes

- Export
  - CSV export now writes the right line endings.
  - IMDI export now writes some genres and roles correctly that it used to get wrong.
  - ELAR IMDI export includes multilingual text that came in through a spreadsheet import. You no longer have to click each field first.
- On a Mac, projects on external drives, USB sticks and network shares no longer fail to open because of the hidden "._" and ".DS_Store" files that macOS puts there.
