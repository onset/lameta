## Improvements

- You can now translate the standard titles and descriptions that IMDI export gives project documents and consent documents.
- "Collection description" is now a genre that you can translate.
- For project documents, IMDI export now adds the collection steward as an actor with the role "research". You can translate that role.
- It is now easier to preview the IMDI for consent documents and project documents.
