This is still a test version of lameta 3.0. If you convert a project's text to multilingual fields, lameta changes the project's files, so make a backup first.

## Improvements

- Text in more than one language
  - Your archive's settings now decide which fields can hold text in more than one language, and which IMDI schema lameta checks against. ELAR uses a draft IMDI 3.0 schema that allows multilingual fields.
  - In a multilingual text field, each language now has its own box, with a hint that says which language goes there. Text whose language lameta doesn't know is marked.

    ![](https://github.com/user-attachments/assets/e85fd99b-8719-4c6c-89b8-5d091a3a2b5d)

  - On the Languages part of the Project tab, a new Metadata Languages list sets the order of the language boxes in multilingual fields. You can drag the languages into a different order.
  - Some projects already keep several languages in one field, separated by slashes. lameta can now convert that text so that it knows which language each part is in. The conversion needs every field to have the same languages in the same order, so lameta waits until you have checked them. Until you finish, lameta opens the project at Project > Languages, where a panel tells you what to do next. You need at least two metadata languages, and lameta warns you if one seems to be missing. IMDI export is not available until the conversion is finished.

    ![](https://github.com/user-attachments/assets/b47c129a-9cfd-40e9-8165-ae0c03bb71c9)

- Translations of genres, roles and other choices
  - In a field where you pick from a list, you can now hover over the field to see the translations that export will use. If one is missing, the field shows a warning icon, and its tooltip links to the place where you can add the translation.

    ![](https://github.com/user-attachments/assets/34363cbc-4209-4634-ab5a-8077475557d2)

  - You can now enter translations of genres and roles.
- Large projects now open 12 times faster.
- Spell checking now also covers Indonesian.
- Right-clicking in a text field now gives you Cut, Copy, Paste and the other usual commands.

## Fixes

- Export and import
  - OPEX export now passes its schema check.
  - CSV export now handles values that contain quotation marks.
  - Spreadsheet import no longer brings in folders that lameta found problems with.
- People and contributions
  - Adding a contribution now works when some contributors aren't on the People tab yet.
  - Two people whose IDs differ only in capitalization no longer cause trouble.
- After you search, the selection no longer jumps to the wrong item.
