This version runs on Windows and on Macs with Apple silicon (M1, M2 and M3). It does not run on Intel Macs.

## Fixes

- lameta now leaves the capitalization of keywords, topics and person codes as you typed it.
- lameta now copes better when OneDrive or another program is holding its files. This mostly affected renaming people and sessions. lameta can't prevent every problem that these programs cause, but it notices more of them, and in some cases it can repair the project.
