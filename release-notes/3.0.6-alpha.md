## Improvements

- Export
  - IMDI export is now much faster. It shows its progress, and you can cancel it. Warnings and errors appear in a box that you can scroll and copy from, with a different color for each kind.

    ![](https://github.com/user-attachments/assets/d91c4828-be64-48be-b47d-dfff424179f3)

  - IMDI export now writes an approximate year such as "~1960" as "1959/1961", which IMDI accepts. It writes a birth date of "?" as "Unspecified".
  - The RO-Crate export has many changes that reviewers asked for.
- Some fields can now hold text in more than one language. For now, only ELAR uses it, on the session's Description field.

  ![](https://github.com/user-attachments/assets/c8a0c9cb-e3d0-4467-b33a-59f375d6e5a0)

- lameta now shows PDF and TIFF files itself.
- lameta now checks spelling in English, French, German, Portuguese and Spanish.
- When a project has many sessions, lameta now shows its progress while the project opens.

## Fixes

- Installed copies of lameta can now export IMDI. Before, only the developers' builds could.
- Access levels are now saved as just their ID. lameta used to save the label as well, which caused problems with projects from lameta 2.3.
