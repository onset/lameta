This is an early test version of lameta 3.0. Opening a project in it may change the project's files, so make a backup before you open one.

## Improvements

- On the Sessions and People tabs, a search box now narrows the list to the items that contain what you type, and shows how many there are. It searches the metadata, the names of files, contributions, notes and status.

  ![](https://github.com/user-attachments/assets/7fdc2b3c-0fe8-49a7-b332-0cb6a51dacca)

- File > Export Project can now make an [RO-Crate](https://www.researchobject.org/ro-crate/), a standard way of packaging research data with its metadata. lameta follows the [LDAC profile](https://github.com/Language-Research-Technology/ldac-profile/blob/master/profile/profile.md). The export writes ro-crate-metadata.json in the project folder, along with ro-crate-preview.html. Anyone can open that page in a browser to see what the project contains, without lameta.

  ![](https://github.com/user-attachments/assets/7d6da225-79d6-4b98-9693-1265f4585d01)

- You can now choose settings for the archive you deposit with: ELAR, AILLA, PARADISEC, TLA, REAP, ANLA or AILCA. An archive's settings can change which fields lameta shows, the vocabularies, the rules for file names, the access choices and what IMDI must contain.

  ![](https://github.com/user-attachments/assets/d415a26f-7644-4d62-b80f-2315450f34bf)

- A project can now have more than one subject language and more than one working language.
- The fields on the Project tab are now grouped under Collection, Funding Project, Languages and Location.
- Each field now shows whether your archive requires it, whether it may hold personal information, and whether it goes into IMDI.

  ![](https://github.com/user-attachments/assets/20d24118-6f28-436c-bac9-c18f624abe87)

- Field hints and warnings are now clearer, and the forms are tidier.
- When a file's name breaks your archive's rules, lameta now says so and offers a button that fixes the name.

  ![](https://github.com/user-attachments/assets/9fcee8b9-cd7f-49cd-99ea-be8f61f0e359)
